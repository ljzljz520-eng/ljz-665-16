# 设备档案 导入/导出 功能说明

## 一、功能清单

| 功能 | 说明 |
|------|------|
| 设备档案 CRUD | 设备编号、名称、类型、部门、位置、责任人；编号唯一 |
| 下载导入模板 | xlsx 模板，含 2 行标题 + 表头，6 列均为必填 |
| 导入-上传校验 | 上传后仅校验、**不入库**：必填项校验 + 编号重复校验（与库中重复、文件内重复） |
| 导入-确认入库 | 校验通过的数据暂存服务端（30分钟有效），点击「确认入库」后才真正落库 |
| 失败行下载 | 校验失败的行可下载 Excel，逐行给出失败原因（含原始数据 + 行号） |
| 按条件导出 | 按列表当前搜索条件导出；若勾选了行则导出勾选数据 |

## 二、后端接口（`/equipment/equipment`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET  | /list              | 分页查询（文本字段全模糊） |
| POST | /add               | 新增（编号唯一校验） |
| POST/PUT | /edit         | 编辑（编号唯一校验，排除自身） |
| DELETE | /delete?id=      | 单条删除 |
| DELETE | /deleteBatch?ids=| 批量删除 |
| GET  | /queryById?id=     | 详情 |
| GET  | /downloadTemplate  | 下载导入模板 |
| POST | /importCheck       | 上传校验（multipart，file 字段） |
| POST | /importConfirm?token= | 确认入库 |
| GET  | /exportImportError?token= | 下载失败行 Excel |
| GET  | /exportXls         | 按搜索条件导出（支持 selections 勾选导出） |

### 校验规则（importCheck）
1. 6 个字段全部必填：设备编号、名称、类型、部门、位置、责任人；
2. 设备编号不能与数据库已有编号重复；
3. 设备编号在同一个导入文件内不能重复；
4. 每条失败行会累加所有失败原因（如"设备编号不能为空；名称不能为空"）；
5. 返回结构：
   ```json
   {
     "success": true,
     "result": {
       "token": "校验批次令牌",
       "totalCount": 100,
       "successCount": 95,
       "errorCount": 5,
       "errorRows": [ { "rowNum": 6, "equipCode": "EQ-001", "...": "...", "errorReason": "设备编号与库中已有数据重复" } ]
     }
   }
   ```
   `errorRows` 仅回传前 10 条用于页面预览，全量失败行通过 `/exportImportError` 下载。

## 三、数据库脚本

执行 `docs/equipment.sql`：
- 建表 `equipment`（equip_code 唯一索引兜底）；
- 写入菜单「设备管理 / 设备档案」及 新增/编辑/删除/导入/导出 5 个按钮权限；
- 为管理员角色（admin）授权。

菜单组件路径：`equipment/equipment/index`，前端页面组件名：`EquipmentList`。

## 五、导入交互流程

1. 列表页点「导入」→ 弹窗内下载模板；
2. 拖拽/选择 xls、xlsx 文件 → 自动调用 `importCheck` 校验；
3. 页面显示总行数、通过行数、失败行数，并预览前 10 条失败原因；
4. 有失败行时可随时「下载失败行」查看全部原因；
5. 点「确认入库（N条）」→ `importConfirm` 落库并刷新列表；
6. 校验结果 30 分钟内有效，过期需重新上传。

# 用户手册

## 访问入口

- 系统地址：`http://localhost:3665`

## 登录

- 默认账号：`admin`
- 默认密码：`123456`

如需确认初始化是否包含账号数据，可在 SQL Server 中查询：

```sql
SELECT username, realname, status FROM sys_user;
```

## 常见功能路径（示例）

不同版本菜单结构可能略有差异，以下为常见模块的使用路径参考：

- **系统管理**：用户/角色/菜单/组织机构/数据字典
- **在线开发**：在线表单、在线报表、代码生成
- **流程与审批**：流程定义、待办、已办

## 基础操作

### 1) 修改密码

一般在右上角用户菜单中进入个人设置或安全设置，完成密码修改。

### 2) 文件上传

系统上传文件默认映射到宿主机目录：`jeecg-boot/data/uploads`。

### 3) 常见问题排查

- 页面无法访问：确认容器是否启动，端口 `3665` 是否被占用。
- 登录报错/空白：查看 `jeecg-backend` 日志是否存在数据库连接失败。
- 初始化失败：查看 `jeecg-sqlserver-init` 日志并根据错误信息重跑初始化。


## 设备档案（设备管理 → 设备档案）

设备档案支持新增、编辑、删除、批量删除，以及 Excel 批量导入导出。

### 1) 导入设备

1. 在设备档案列表点击 **导入**，在弹窗中先点击 **下载导入模板**。
2. 按模板填写：**设备编号、名称、类型、部门、位置、责任人**（均为必填）。
3. 选择文件后系统自动校验：
   - 必填项是否为空；
   - 设备编号是否在文件内重复；
   - 设备编号是否与系统中已有数据重复。
4. 校验结果页展示总行数、通过行数、失败行数及数据预览。
   - 有失败行时可点击 **下载失败行文件**（.xlsx，含原始数据与"失败原因"列）查看具体原因，失败行不会入库；
   - 校验通过的数据需点击 **确认入库** 后才会真正写入（校验结果 30 分钟内有效，过期需重新上传校验）。
5. 确认前再次点击导入/取消均不会产生数据。

### 2) 导出设备

- 列表页设置查询条件后点击 **导出**，系统按**当前搜索条件**导出全部匹配数据；
- 若勾选了列表中的若干行，则仅导出勾选的行。

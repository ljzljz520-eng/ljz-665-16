# 开发指南

## 目录结构

- `docker-compose.yml`：一键启动编排。
- `backend/`：后端工程（Spring Boot / Maven 多模块）。
- `frontend/`：前端工程（Vue3 / Vite）。
- `db/sqlserver/`：MySQL→SQL Server 初始化转换逻辑。

## 一键启动（推荐）

在项目根目录 `jeecg-boot/`：

```bash
docker compose up -d
```

访问：

- 前端：`http://localhost:3665`
- 后端：`http://localhost:8665`

默认账号密码：`admin/123456`。

## 常用开发操作

### 1) 仅重跑数据库初始化

当修改了初始化脚本或转换器后，建议先重建数据库再重新运行 `db-init`：

```bash
docker exec jeecg-sqlserver /opt/mssql-tools18/bin/sqlcmd -S localhost -U sa -P "${MSSQL_SA_PASSWORD:-Supcon1304}" -C \
  -Q "IF DB_ID(N'temp1218') IS NOT NULL BEGIN ALTER DATABASE [temp1218] SET SINGLE_USER WITH ROLLBACK IMMEDIATE; DROP DATABASE [temp1218]; END; CREATE DATABASE [temp1218];"

docker compose up -d --force-recreate db-init
```

### 2) 查看初始化日志

```bash
docker logs jeecg-sqlserver-init --tail 200
```

### 3) 查看后端日志

```bash
docker logs jeecg-backend --tail 200
```

### 4) SQL Server 连接与快速校验

```bash
docker exec jeecg-sqlserver /opt/mssql-tools18/bin/sqlcmd -S localhost -U sa -P "${MSSQL_SA_PASSWORD:-Supcon1304}" -C -d temp1218 \
  -Q "SELECT COUNT(1) AS user_count FROM sys_user;"
```

## 设备档案模块（业务模块示例）

新增业务模块位于后端 `org.jeecg.modules.equipment`（随 jeecg-system-biz 启动自动扫描），前端位于 `frontend/src/views/equipment/archive`。

### 后端结构

- `entity/EquipmentArchive`：设备档案实体（`equipment_archive` 表），编号 `equip_no` 唯一。
- `vo/EquipmentImportVO`：导入/模板 Excel 列模型（设备编号、名称、类型、部门、位置、责任人）。
- `vo/EquipmentImportCheckVO` / `EquipmentImportErrorVO`：导入校验结果、失败行（含失败原因）。
- `util/EquipmentImportErrorFileUtil`：生成失败行 xlsx，落盘到 `${jeecg.path.upload}/logs/{yyyyMMdd}/`，通过 `/sys/common/static/**` 下载。
- `service/impl/EquipmentArchiveServiceImpl`：两步入库核心逻辑。
- `controller/EquipmentArchiveController`：列表/增删改查、`importTemplate`、`importCheck`、`importConfirm`、`exportXls`。

### 两步入库流程

1. `POST /equipment/archive/importCheck`：AutoPoi 解析（2 行标题 + 1 行表头），校验 6 个必填项、文件内编号重复、库中编号重复；结果与完整通过列表以 JSON 存入 Redis（key 前缀 `equipment:import:check:`，TTL 30 分钟），不写库；失败行同步生成 xlsx。
2. `POST /equipment/archive/importConfirm?checkToken=xxx`：读取缓存，入库前再次查重（防并发），`saveBatch` 入库后凭证立即失效；仍有失败时返回 `code=201` 并给出新的失败文件地址。

### 导出

`GET /equipment/archive/exportXls` 复用 `JeecgController.exportXls`，以 `QueryGenerator.initQueryWrapper` 按请求参数（当前搜索条件）过滤；`selections` 参数非空时只导出勾选行。

### 数据库脚本

见 `backend/db/equipment/README.md`：新环境由 `db/sqlserver/entrypoint.sh` 自动追加 `equipment_init_append.sql`；已部署环境使用幂等的 `equipment_archive_*.sql` 与 `equipment_menu_*.sql` 手动升级。
